# Contributing

swarm-kg is a personal proof of concept, and it isn't open to contributions
yet.

- **Issues and pull requests are open to collaborators only.** The issues here
  are my own specs and tickets for building swarm-kg.
- **A question, an idea or a bug?** Get in touch with me directly.
- **Want to build on it?** Fork it: it's MIT-licensed (see [LICENSE](LICENSE)).

If that changes, this file will say how to contribute.

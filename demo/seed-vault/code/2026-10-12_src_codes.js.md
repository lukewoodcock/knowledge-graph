## Summary
`src/codes.js` turns the link counter into a short code: `encode(n)` writes `n` in base62 (`0-9a-zA-Z`), and `decode(code)` reverses it. Codes are as short as the counter allows: 62 links fit in one character, 3,844 in two.

## Key Points
- `encode(0)` is `"0"`; negative or non-integer input throws.
- `decode` rejects any character outside the alphabet, so a bad code is a 404 rather than a wrong link.

## Notes
Sequential codes are guessable; see the open todo on rate limiting the create endpoint.
